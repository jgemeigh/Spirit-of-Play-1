# Spirit of Play: Jacob VS The Weather

A browser game by LFS Gaming × sound.wav.

## Run locally

Serve this folder through a small local web server so the browser can load the separate audio files:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000`.

## Publish with GitHub Pages

1. Create a repository.
2. Upload `index.html`, `README.md`, and the entire `audio` folder.
3. Open **Settings → Pages**.
4. Choose **Deploy from a branch**, select `main` and `/ (root)`, then save.

Every individual file is below GitHub's 25 MB browser-upload limit.
